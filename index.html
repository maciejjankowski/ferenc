Ferenc · quick reference

Sound

TRIG SRC FLTR AMP FX MOD select the parameter page for knobs A–H. Press a page again for its 2nd page (SRC on GRAN, MOD = LFO1/LFO2).

FUNC + SRC cycles the machine: WAVE (single cycle / wavetable oscillator, unison), SMPL (sample playback), GRAN (granular cloud).

Knobs: drag up/down or wheel. Shift = fine. Double-click = default (or clear lock).

Samples

Drop WAV/AIFF/MP3/FLAC files anywhere, or open the Samples button. Files ≤ 4096 samples are single cycles (band-limited wavetables). Serum clm wavetables are detected. Stored in the browser.

Sequencer

Click a trig key to toggle a step. Long-press / right-click / FUNC+key latches a step: knobs now set parameter locks for it (NO to release). ◀ ▶ nudge µ-timing of the locked step.

TRK + key = select track, FUNC+TRK = mute mode. PTN + key = pattern (queued while playing), FUNC+PTN = bank. PAGE = next 16 steps, hold = FILL.

REC arms live recording (quantize: FUNC+TRIG). FUNC + REC/PLAY/STOP = copy / clear / paste (NO undoes).

KB turns trig keys into a keyboard (FUNC+KB: scale/root).

Computer keys · Tab toggles EDIT / PLAY

EDIT (default): 1–6 TRIG SRC FLTR AMP FX MOD (again = 2nd page) · 7 delay/reverb · 8 mixer · 9 sequencer · 0 samples · Q W E R / A S D F = knobs A–H: hold + move the mouse (no click) to change, or tap to select then scroll / ↑↓ · Backspace reset · Z X C V B N M , tracks 1–8 (Shift = mute) · G preview note

PLAY: A W S E D F T G Y H U J K O L P notes · Z / X octave · 1–8 track

Both: Space play/pause · Shift = FUNC / fine · Enter YES · Esc NO · ←→ page/µtime · [ ] step page · ? help

MIDI

Gear button: ports, channel, clock in/out, thru. Notes play the active track (or per-track channels via FUNC+FLTR). CC 16–23 = knobs A–H, 74 cutoff, 71 reso… Sequencer notes can be sent out per track.
